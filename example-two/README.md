# Worked Example Two: No Advocate Has Actually Agreed

The first [example](../example/) tests whether the tool bases each point on evidence rather than a job title. This one tests something else. When no advocate has agreed to carry the case, the tool should refuse to write a briefing at all, rather than write one anyway and hope someone uses it.

- [inputs.md](inputs.md): a request for a briefing for a colleague who hasn't been asked yet
- [output.md](output.md): the response, which stops rather than writing a briefing
- [review.md](review.md): whether the tool held firm rather than helping anyway "just in case"
