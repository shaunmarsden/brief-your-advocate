# Worked Example Two: No Advocate Has Actually Agreed

The first [example](../example/) tests mapping people to actual evidence rather than titles. This one tests a different guardrail: refusing to produce a briefing at all when no advocate has actually agreed to carry the case, rather than preparing material anyway and hoping someone will use it.

- [inputs.md](inputs.md): a request to prepare a briefing for a colleague who has not actually been asked yet
- [output.md](output.md): the response, which correctly stops rather than producing a briefing
- [review.md](review.md): whether the tool actually held the line rather than helping anyway "just in case"
